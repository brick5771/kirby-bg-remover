# 🌟 星之卡比桌面去背精靈 (Kirby BG Remover)

一款可愛的 Windows 透明懸浮桌面 AI 去背工具：把圖片拖進星之卡比的嘴巴，圖片會邊旋轉邊縮小吸進嘴裡，消化完畢後透明去背 PNG 會從卡比**左後方的背部**帶著星星特效彈出！

## 主要功能
- **透明無邊框桌面懸浮**：直接浮在 Windows 桌面上，支援自由拖曳移動、系統匣圖示與總是置頂切換。
- **三種餵圖方式**：
  - 直接拖曳圖片檔案到卡比嘴巴（也支援直接把圖片拖到桌面捷徑上）
  - 點擊卡比嘴巴（或連點兩下身體）選取圖片
  - 選中視窗後按 `Ctrl+V` 直接貼上剪貼簿截圖或圖片
- **本機免費 AI 去背（完全離線）**：
  - `⚡ 快速`（預設，`silueta`，約 0.6–0.8 秒）
  - `✨ 均衡`（`isnet-general-use`，約 1 秒，人物與動漫邊緣更銳利）
  - `💎 精細`（`birefnet-general-lite`，髮絲與複雜輪廓專用）
- **去背結果預覽卡**：
  - 一鍵 **💾 儲存去背圖**（無損透明 PNG，`Ctrl+S`）
  - 一鍵 **📋 複製透明 PNG**（直接貼進 PPT、Line、Discord、Photoshop、Figma，`Ctrl+C`）
  - **透明格 / 淺白 / 深黑** 三種預覽底色切換
  - 右上角即時切換去背模型並自動重新去背
- **可愛復古合成音效**：吸入、吞嚥、背部彈出與儲存音效（附一鍵靜音）。

## 快速安裝與啟動（Windows 10 / 11）
1. 確認電腦已安裝 Python 3.10–3.12（或 [`uv`](https://docs.astral.sh/uv/)）。
2. 下載或 clone 本專案後，直接點兩下 **`安裝並啟動.bat`**。
3. 腳本會自動建立 `.venv`、安裝 `requirements.txt`、在桌面建立星之卡比圖示捷徑並啟動程式。

## 專案結構
- `main.py` — 程式進入點與單一實例管理
- `kirby_widget.py` — 透明懸浮卡比與 60fps 吸入／背部彈出動畫引擎
- `result_card.py` — 去背結果預覽卡、底色切換、儲存與模型選擇
- `bg_worker.py` — 本機 `rembg` ONNX 背景執行緒與模型快取
- `clipboard_win.py` — Windows 透明 PNG 剪貼簿讀寫
- `sound_fx.py` — 復古遊戲風格程式合成音效
- `assets/` — 星之卡比素材圖、`kirby.ico` 與合成音效檔
