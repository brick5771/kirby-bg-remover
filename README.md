# 🌟 星之卡比桌面去背精靈 (Kirby BG Remover)

一款可愛的 Windows 透明懸浮桌面 AI 去背工具：把圖片拖進星之卡比的嘴巴，圖片會邊旋轉邊縮小吸進嘴裡，消化完畢後透明去背 PNG 會從卡比**左後方的背部**帶著星星特效彈出！

## 主要功能
- **透明無邊框桌面懸浮**：直接浮在 Windows 桌面上，支援自由拖曳移動、系統匣圖示與總是置頂切換。
- **三種餵圖方式（皆支援單張＆複數多張批次處理！）**：
  - 直接拖曳單張或多張圖片檔案到卡比嘴巴（也支援一次拖多張圖到桌面捷徑上）
  - 點擊卡比嘴巴（或連點兩下身體）複選多張圖片
  - 選中視窗後按 `Ctrl+V` 直接貼上剪貼簿裡的截圖，或一次貼上在檔案總管複製的多張圖片
- **本機免費 AI 去背＆彩色轉黑白（完全離線）**：
  - `⚡ 快速去背`（預設，`silueta`，約 0.6–0.8 秒）
  - `✨ 均衡去背`（`isnet-general-use`，約 1 秒，人物與動漫邊緣更銳利）
  - `💎 超精細去背`（`birefnet-general-lite`，髮絲與複雜輪廓專用）
  - `🖤 純轉黑白`（不去背、保留原背景，瞬間將彩色圖轉成高質感黑白灰階）
  - `🌗 去背＋黑白`（一次完成去背並將主體轉成黑白透明 PNG）
- **去背結果預覽卡（單張／多張縮圖切換）**：
  - 單張時一鍵 **💾 儲存** / **📋 複製透明 PNG**；多張時自動顯示縮圖切換列，支援 **💾 全部儲存 (N張)** 至資料夾與 **📋 複製全部 (N張)**（一次把 N 張 PNG 放進剪貼簿，直接 `Ctrl+V` 貼進桌面、資料夾、Line、Discord、PPT！）
  - 一鍵 **🖤 轉黑白** 即時濾鏡切換（在彩色去背結果上可立即套用到全部圖片）
  - **透明格 / 淺白 / 深黑** 三種預覽底色切換
  - 右上角即時切換模式並自動重新處理
- **可愛復古合成音效**：吸入、吞嚥、背部彈出與儲存音效（附一鍵靜音）。

## 快速安裝與啟動（Windows 10 / 11）
1. 下載或 clone 本專案（若從 GitHub 按 **Code → Download ZIP**，請先完整解壓縮）。
2. 直接點兩下 **`安裝並啟動.bat`**（**不需要**事先手動安裝 Python）。
3. 腳本會自動：
   - 偵測並安裝 `uv`（若尚未安裝），並自動下載相容的 **Python 3.12** 建立 `.venv` 虛擬環境與安裝 `requirements.txt`（避免 Python 3.15 等過新版本與 `onnxruntime` 不相容）。
   - 在**桌面**與**本專案資料夾內**自動建立 **`星之卡比去背.lnk`** 捷徑（附星之卡比圖示）。
   - 啟動星之卡比去背精靈（首次使用某個去背模型會自動下載模型檔，之後可離線使用）。

> 💡 之後只要直接點桌面或資料夾裡的 **`星之卡比去背`** 捷徑即可啟動，不需要再跑安裝！

## 專案結構
- `main.py` — 程式進入點與單一實例管理
- `kirby_widget.py` — 透明懸浮卡比與 60fps 吸入／背部彈出動畫引擎
- `result_card.py` — 去背結果預覽卡、底色切換、儲存與模型選擇
- `bg_worker.py` — 本機 `rembg` ONNX 背景執行緒與模型快取
- `clipboard_win.py` — Windows 透明 PNG 剪貼簿讀寫
- `sound_fx.py` — 復古遊戲風格程式合成音效
- `安裝並啟動.bat` / `install_and_run.ps1` — 一鍵環境安裝、建立捷徑與啟動腳本
- `assets/` — 星之卡比素材圖、`kirby.ico` 與合成音效檔
